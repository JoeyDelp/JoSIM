    Safe external sweeps — 6 November 2026

    This resolves the unsafe ivcurve.py prototype and supplies bounded alternatives for #82/#84. It does not introduce an internal multidimensional sweep engine. The guide distinguishes model, fresh-point and continuous-history measurements and gives executable commands.

    Reproduced failure and disposition

    The original script assumes the current is token 9 on physical line 2. It derives output/temp names through case-sensitive .cir replacement, edits files directly, ignores subprocess status and reads fixed CSV columns. Its phase-derived voltage calculation also has incorrect dimensions.

    A bounded probe used task-owned inputs and an existing input_tmp.cir sentinel. The simulator wrapper ran real JoSIM once, then returned status 17. Within five seconds the script made 292 calls, overwrote the sentinel and repeatedly reused the first CSV despite subsequent failures. The original main netlist was unchanged in this particular probe. The defect is the demonstrated unrelated temporary-file overwrite and unchecked/stale execution, not a claim that every input filename is overwritten. Exact old script/binary hashes and witnesses are in build/audit-resolution/sweeps/unsafe-iv/red.json and red.log.

    The prototype is formally retired. Its old entry point now returns status 2 with useful alternatives and changes no files. Git preserves its history. This avoids retaining a misleading special-purpose script as a supported general circuit-IV workflow.

    Replacement ownership and numerical checks

    tools/circuit_sweep.py replaces a finite numeric @VALUE@ marker in a main template and launches one fresh CLI process per value. Standard input plus the template working directory preserves relative source paths. Preflight checks all reachable include contexts, rejects FILE/IV output directives, and hashes netlists/includes/custom data. Generated output uses a new directory and a unique absolute CLI output path per point. No original netlist is edited. Every result records effective seed/grid and source/binary/output identity.

    The explicit-window average is

    \[ \bar y=\frac{1}{t_b-t_a}\sum_k \frac{y_k+y_{k+1}}2(t_{k+1}-t_k), \]

    using the piecewise-linear trace clipped/interpolated to the two boundaries. No extrapolation is permitted. A deliberately nonuniform grid for y=2t has exact mean 3.5 over [0.5,3], which independently checks boundary clipping and weighting. Invalid/nonfinite/duplicate timestamps fail cleanly.

    Native regression assertions include:

    • Five R=1/2/3/4/5-ohm points driven by 1 A: each mean agrees with IR within 1 nV in both analysis modes. Controlled seed 123 and 20 computed points are recorded, and source/existing-temp-file/result-directory byte preservation is required.
    • A complete two-junction zero-L circuit at -200/0/+200 uA: independent overdamped mean voltages are -1.13137085/0/+1.13137085 mV. Measured values are -1.13153468/0/+1.13153468 mV in both modes, 0.0145% relative error. The 1% bound includes endpoint phase uncertainty <=Phi0/(490 ps)=4.23 uV and timestep/CSV error at about 183 points per Josephson period.
    • Relative nested inputs and a continued mixed-case CUS waveform: resistor currents agree with 1/R within 1 nA, external-data hashes are recorded, and all input bytes remain unchanged. Filenames/working paths contain spaces.
    • Nested FILE/IV rejection happens before execution/output creation. Invalid values/windows/timeouts and recursive includes fail usefully. A simulator error stops at its first point with no summary CSV or stale-data reuse.
    • A bounded timeout preserves the effective input and partial log as a failure. The retired prototype cannot modify either a source or an existing temp file.

    The helper supports one numeric marker in the main template, fixed include/data filenames and within-file continuations. It does not silently transform model IV directives, interpolate solver states, promise stationary noise from one record, or carry state between independent points. General multidimensional sweeps remain external orchestration, with explicitly chosen combinations and state/seed policies.

    Qualification

    The new standard-library regression::sweep group is required by binary and installed-library qualification. All four local compiler/configurations pass 34/34 CTest groups. The final expanded nine-test sweep group passes all four configurations and ASan/UBSan with leak detection in 4.02 s. The preceding production revision passed the complete 33-group sanitizer suite in 209.52 s; this batch changes Python workflows/test registration, with no C++ equation or runtime change. Broader Plotly/Pandas utility/dependency work remains separate under D05.

    Reproduce from the repository root:

    ctest --test-dir build/dev -R regression::sweep --output-on-failure --no-tests=error

    Detailed source hashes, exact red witnesses, analytic measurements and compiler/ sanitizer receipts are under build/audit-resolution/sweeps/ and compact artifacts/audit-resolution/sweeps/. Native final-revision qualification remains pending; no version/release/site completion is implied.
