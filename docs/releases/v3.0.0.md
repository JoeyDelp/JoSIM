# JoSIM 3.0.0

This release consolidates the public branches and original noise research,
repairs the audited simulator and library defects, and updates the maintained
builds, tools and documentation. JoSIM remains freely available under MIT.

**Recompile C++ applications with matching 3.0.0 headers and libraries.** Public
type layouts changed. CMake package selection now uses major 3; shared Unix
libraries carry ABI version 3. Existing `v2.7` remains unchanged.

## Changes

- Repair hierarchical parameters/models, pin aliases, requested traces and
  startup/phase histories. Reject malformed input and failed output explicitly.
- Correct seeded replay, white/colored-noise normalization and state-dependent
  thermal noise. Add controlled gate, flux and critical-current noise workflows.
- Rebuild device histories per model-IV point and preserve bias through retries.
  Add explicit sweep timing, a safe external circuit-sweep owner and tested examples.
- Add analytic linear-network, junction, buffer, phase, stochastic and conservation
  regressions. Protect first-party coverage and complete qualification inventories.
- Make supported embedding failures recoverable, qualify relocated installed
  consumers, and retire nonfunctional SuperLU/parallel options explicitly.
- Reduce avoidable history allocation, per-step copies and progress polling.
  Controlled studies show 13–20% lower peak memory and 15–21% lower wall time in
  selected workloads; these are measured cases, not universal speed guarantees.
- Refresh English/Japanese manuals, packaged guides, plotting utilities and
  build/release procedures. Fix PULSE cycle overflow and advertised CLI options.

## Downloads

Choose the archive matching your OS and CPU. Each archive has a `.sha256`
sidecar and source/toolchain/payload manifest. The executable is in `bin/`.

| Target | Runtime requirement |
|---|---|
| `linux-x64-rhel6` | x86_64, glibc 2.12 |
| `linux-arm64-rhel7` | AArch64, glibc 2.17 |
| `windows-x64` | Windows 10+, x64; static MSVC runtime |
| `macos-arm64` | macOS 11+, arm64 |
| `macos-x86_64` | macOS 10.15+, Intel |

Linux qualification uses legacy userspaces on modern kernels. macOS deployment
metadata does not establish execution on every older OS release. See
[compatibility](https://github.com/JoeyDelp/JoSIM/blob/v3.0.0/docs/compatibility.md).
The tagged workflow builds and checks all five targets before publication, then
downloads the actual public assets and executes CLI/numerical regressions natively.

## Model and workflow limits

Each transient attempt uses a fixed step. A smaller-step retry restarts the
whole run; this is not conventional adaptive error control. Validate timestep,
settling and output sampling for your circuit. Noise replay requires the same
build, seed and effective sampling settings. Model `.iv` is a finite single-JJ
testbench, distinct from an arbitrary-circuit sweep. Capacitor `IC=`, a direct
`BETA_C=` field and nonlinear inductors remain outside the supported model;
documented preparation/conversion alternatives are provided.
