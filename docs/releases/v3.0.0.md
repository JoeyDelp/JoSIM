# JoSIM 3.0.0

This release adds gate-controlled junctions, power-law and flux noise sources,
and a script for sweeping circuit parameters. It also fixes several problems
with subcircuits, junction phase, startup and noise calculations.

## New features

- Gate-controlled junctions with `GC=` and `GWIDTH`.
- Power-law, flux and fractional critical-current noise sources.
- Circuit parameter sweeps using `tools/circuit_sweep.py`.
- Model IV timing controls: `TSTEP`, `TSTOP` and `TSTART`.
- Static and shared C++ library builds with CMake package support.

## Fixes

- Named subcircuit parameters, local models and hierarchical pin outputs.
- Phase error that accumulated in long voltage-mode junction simulations.
- Junction and phase-source histories during startup.
- Noise bandwidth, power-law normalization and junction thermal noise during switching.
- Seeded runs repeated in the same process.
- Model IV state and bias handling between points and after timestep restarts.
- Waveform parsing, output errors and plotting scripts.
- Excessive progress-display CPU use and avoidable result-storage allocations.

The [changelog](https://github.com/JoeyDelp/JoSIM/blob/master/CHANGELOG.md)
has the full list. See the [manual](https://joeydelp.github.io/JoSIM/) for syntax
and examples.

C++ applications must be rebuilt with the 3.0.0 headers and libraries.
The old SuperLU/OpenMP options and the `ivcurve.py`/`noise_insert.py` prototypes
are no longer supported; the manual describes their replacements.
