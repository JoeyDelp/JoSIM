# JoSIM 3.1.0

This release adds direct Stewart–McCumber damping input, capacitor initial
voltages and quadratic nonlinear inductors. Each works in voltage and phase
analysis. It also corrects the history ordering of voltage-mode mutual inductors.

## New features

- **Junction damping:** `BETA_C=` sets the nominal Stewart–McCumber parameter
  for an `RTYPE=0` model. JoSIM calculates RN from BETA_C, Ic and C. All three
  must be finite and positive. An explicit RN or temperature-dependent model
  parameters cannot be combined with BETA_C. See the
  [damping guide](https://joeydelp.github.io/JoSIM/model_limits/#beta-c).
- **Capacitor initial voltage:** `C1 N 0 1p IC=1m` starts with 1 mV across
  the capacitor. Add `DST` to `.TRAN` to disable settling. JoSIM computes
  consistent initial currents and histories, including after timestep restarts.
  These IC runs do not yet support phase sources or controlled sources. See the
  [initial-state guide](https://joeydelp.github.io/JoSIM/model_limits/#capacitor-voltage).
- **Nonlinear inductors:** `L1 IN OUT 100p ALPHA=1e8` specifies differential
  inductance `Ld(I)=L0*(1+ALPHA*I^2)`, with self flux
  `Phi=L0*(I+ALPHA*I^3/3)`. ALPHA is finite and non-negative, in A^-2.
  Reciprocal mutual coupling uses constant M based on the zero-current L0
  values; groups containing nonlinear inductors require a positive-definite
  base inductance matrix. Both modes use bounded Newton correction and timestep
  retries. See the
  [inductor guide](https://joeydelp.github.io/JoSIM/model_limits/#nonlinear-inductance)
  and [LC example](https://github.com/JoeyDelp/JoSIM/blob/v3.1.0/test/comp/nonlinear_inductor.cir).

## Updating

C++ applications, including those built for 3.0, must be rebuilt with matching
3.1 headers and libraries. Public type layouts have changed. Shared libraries
use ABI version 4, independently of the JoSIM release version. See
[compatibility guidance](https://joeydelp.github.io/JoSIM/compatibility/).

The mutual-inductor history correction can change existing voltage-mode results.
Check timestep convergence when comparing coupled circuits with earlier versions.
