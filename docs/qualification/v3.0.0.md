## Quantitative scientific evidence

Individual studies version the equations, independent references, tolerances and commands. Selected measured results:

- [Linear circuits](2026-11-06-linear-circuits.md): 36 RC/RL/RLC cases; maximum finest-step voltage errors 13.1534/13.1534/14.0995 nV, KVL <= 5.00001e-10 V, KCL zero at CSV precision, error decreases 3.4–4x on step halving. Additional matched-line 36, controlled-source 72 and reversed/floating-capacitor 12 cases protect signs/delays and conservation.
- [RSJ](2026-11-06-rsj.md): period errors 567.504/142.585/35.6945 ppm under refinement; mean pulse area agrees with SI Phi0 within 0.092 ppm over 820–821 rotations. [Phase study](2026-11-06-junction-phase.md) uses an independent 70-digit prediction for long-run drift.
- [Buffer](2026-11-06-buffer.md): tightened Radau and independent BDF agree within 2.05e-10 scaled state units (1e-8 budget). Finest-step waveform errors 19.1501/40.5556 nV reverse/forward. Pulse-area allowance 5e-6 Phi0; reverse net response -1.38349e-6 Phi0 and forward 0.999997568 Phi0.
- [Thermal/white](2026-11-06-white-thermal-noise.md): interpolation gives NEB = 1/(3B); six state-dependent circuit checks have maximum 5.114e-13 A discrepancy against independently computed SI amplitudes (1 ppm + 1e-14 A bound). Classical S_I=4kBTG is the stated physical approximation.
- [Colored noise](2026-11-06-colored-noise.md): pole-bank/sample-gain corrections checked across 48 banks and controlled seeds, with declared variance/PSD budgets. Delay/tick/retry and flux/current units are independently tested.
- [SQUID](2026-11-06-squid-noise.md): finite-loop flux residual <= 3.713e-9 Phi0 (5e-7 budget); 16 seeds at each of three NEBs yield PSD/reference ratios 1.020164/0.998104/0.992709, inside family 99% intervals plus 5% model allowance. Halving timestep/output spacing changes PSD <= 0.1413%/0.0612%.
- [Storage](2026-11-06-runtime-storage.md): 112 paired controlled runs retain identical CSVs. Noise peak RSS 102.77→89.45 MiB; 32-voltage bank 199.77→159.49 MiB. [Borrowed views](2026-11-06-runtime-storage.md#per-step-vector-copies) and [progress](2026-11-06-runtime-storage.md#progress-workers) record separately controlled time/CPU reductions and unaffected-case bounds. These are workload-specific measurements.

## Compatibility and remaining boundaries

Version 3 is justified by changed public C++ layouts. Recompile with matching headers/libraries and compatible toolchains; Unix shared objects carry ABI 3 and CMake selection uses SameMajorVersion. CSV/DAT/RAW conventions and supported KLU ownership remain documented. [Migration](../compatibility.md) details intentional corrected behaviour and retired options.

Linux x64 claims glibc 2.12 and ARM64 glibc 2.17. Legacy userspaces execute on modern kernels; this does not qualify original RHEL kernels. Windows uses the static MSVC runtime. Apple Silicon/Intel deployment targets remain 11.0/10.15, while CI executes its actual current runner OS; metadata does not establish every older macOS release.

Each attempt uses a fixed step; smaller-step failure recovery restarts the whole run. No conventional adaptive error-control/Newton guarantee is added. Check timestep, settling and output sampling for each model. Noise replay requires matching build/seed/effective sampling. Global RNG ownership permits sequential runs on one designated thread; use process parallelism. Decimation does not reduce stored internal histories, whose double payload scales as 8*N*(1+retained unknowns+requested applied-current histories).

The bounded analytic/stochastic/model studies resolve the audited supported behaviours. They do not establish every SPICE dialect, arbitrary public-container mutation, every physical regime, quantum noise, original undocumented screenshots or a nonlinear-inductor solver.
