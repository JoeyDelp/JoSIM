# Model-IV retry qualification — 6 November 2026

This study resolves F22, a bias-loss defect exposed while checking model-IV
physics. It is separate from averaging-window accuracy: the historical 500 ps
protocol cannot by itself guarantee a converged DC mean for every model.

## Independent reproduction

Use a junction with `RTYPE=0`, `ICrit=0`, `CAP=0` and `RN=100`, then request
`.IV M 1m iv.csv STEP=1m`. Its constitutive law is simply

\[
V=R_N I.
\]

The four requested points are `[+1 mA, 0, −1 mA, 0]`, so the expected voltages
are `[+0.1 V, 0, −0.1 V, 0]`. The default 0.05 ps step gives phase advance
\(hV/\sigma\approx15.2\) rad at 0.1 V, exceeding the 0.2-cycle restart guard.
Repeated step reductions are therefore exercised, including during the bias
ramps. This expectation uses Ohm's law, not JoSIM-generated reference data.

Before repair, **all four rows instead contained 2.5 µA and 250 µV**, and the
CLI returned success. `generate_iv` changed only the active source function;
`Simulation::reduce_step` rebuilt the matrix from Input's original hardcoded
2.5 µA PWL declaration. It consequently changed both the simulated voltage and
the reported current. This was more than an output-label error.

The IV owner now keeps each generated PWL declaration synchronized with its
active function before simulation. The generic retry mechanism continues to
rebuild from Input, retaining its existing state-reset and RNG semantics.
No existing public signature, class layout, timing default, physical constant
or file format changes. The repaired probe gives exactly the four requested
currents and Ohmic voltages at the existing CSV precision.

## Regression scope

`regression::gate` adds four cases: gated and ordinary model testbenches, each
invoked from both caller analysis modes. Model IV continues to use voltage
analysis internally. Every case checks all four current/voltage rows against
the independent values above, with absolute bounds `1e-12 A` and `1e-8 V`.
These expected literals are exactly representable in the existing scientific
CSV notation; the voltage bound is a conservative allowance for a linear solve
and late-window sample averaging, not a nonlinear convergence tolerance.

The existing suite also checks STEP/ISTEP endpoints, gate polarity/voltage units,
subcircuit gate lookup, physical-temperature settings, scoped model defaults and
invalid gate/IV declarations. This repair does not claim arbitrary circuit
sweeps or a general DC solver.

All four local GCC 16.2.1/Clang 23.1.4 Debug/Release configurations compile and
pass **34/34** CTest groups. The four affected sanitizer groups—gate, CLI,
library and JTL/model-IV integration—pass with ASan/UBSan and leak detection
in **34.52 s**. The immediately preceding full output-repair sanitizer campaign
passed 34/34 in 211.84 s; this focused rerun exercises the new IV source changes.
